# SQL-project

This repository contains SQL projects and practical exercises designed to develop my database management and data analysis skills.

I use SQL to retrieve, manipulate, clean, and analyze data to generate meaningful business insights.

### Topics Covered
- SQL Basics (DDL, DML, DQL, DCL, TCL)
- SELECT, WHERE, ORDER BY, GROUP BY
- Aggregate Functions
- Joins (INNER, LEFT, RIGHT, FULL)
- Subqueries and Nested Queries
- SQL Operators
- CASE Statements
- Views and Indexes
- Stored Procedures and Triggers
- Window Functions
- Common Table Expressions (CTEs)
- Data Cleaning and Analysis

### Tools Used
- MySQL
- MySQL Workbench

### Objectives
- Improve SQL query-writing skills.
- Analyze datasets using SQL.
- Solve real-world business problems.
- Develop database management knowledge.
- Build practical experience in data analytics.

**Skills:** SQL | MySQL | Data Analysis | Database Management | Query Optimization
